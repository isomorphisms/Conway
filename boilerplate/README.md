# Boilerplate

This directory holds the delivery machinery and historical material that should not obscure the pattern language or wallpapers at the repository root.

- `android/` — Android app, Gradle build, and native renderer
- `fdroid/` — F-Droid metadata
- `fastlane/` — Android listing metadata
- `archive/` — the earlier Cayley prototype snapshot
- `migration-notes.md` — the Cayley-to-Conway separation notes
- `third-party.md` — external licensing and toolchain notes

The project-facing material lives in [`../pattern-language/`](../pattern-language/) and [`../wallpapers/`](../wallpapers/).
